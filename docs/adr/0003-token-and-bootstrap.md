# ADR 0003：BOLT 代幣、無創世分配與啟動期

- 狀態：已採納（2026-09-25）

> **2026-09-26：發行規則已被 ADR 0012 取代。** 沒有總量上限；每塊 32 BOLT（共識 31 + 存儲 1），每 4 年減半，最終固定為共識 1 + 存儲 1；燒掉的手續費不再回到任何池子。
>
> 2026-09-26（稍早）：發行分配曾改為共識 60% / 存儲 20% / 算力 20%（ADR 0011），也已被 ADR 0012 取代。
>
> **2026-09-25：啟動期部分已被 ADR 0007 取代。** 改為以 CPU 友善的 PoW 啟動，質押最終性逐步接手；沒有 genesis 驗證者，也沒有鎖倉或折扣規則。代幣參數與 chain id 仍然有效。

## 決定

- 代幣 BOLT，總量上限 2^32 = 4,294,967,296 枚（18 位小數），沒有創世分配。
- 每個 epoch 發行「未發行池 × k」，k = 1 − 2^(−1/1460)，半衰期 4 年。首日約 2,038,587 BOLT。
- EIP-1559 燃燒的 base fee 回到未發行池，所以流通量永遠不超過上限。
- 發行分配：80% 給投票參與，20% 給歷史存儲抽查通過者（不需質押，從第一天就對所有人開放）。
- 最低質押 64 BOLT。
- 啟動期：genesis 列出至少 7 個驗證者的 BLS 公鑰（不分配代幣），以等權重出塊；
  獎勵打 25% 折並鎖倉。在同一個 epoch 內達到至少 128 名質押者、總質押 ≥ 1,000 萬 BOLT 時，
  下一個 epoch 起改為依質押權重抽委員會。
- 治理：Safe 多簽 5-of-9 + timelock（升級 16 天、參數微調 2 天）；硬性邊界寫死在合約內。

## 後果

- 啟動期內的安全性等同聯盟鏈，需要對外揭露。
- 最低質押很低，驗證者可能多達數萬個：獎勵必須用延遲結算、抽籤必須用 Fenwick tree，避免 O(N) 操作。
- genesis 驗證會拒絕任何餘額非零的 `alloc` 帳戶。

## 補充：本地開發鏈（2026-09-25）

genesis 加入 `"dev": true` 旗標。只有開發鏈可以在 `alloc` 裡注資帳戶，而且開發鏈**不得**使用 chain id 8017，
以免開發用的交易被重放到 Boltchain。主網 genesis（`dev` 為 false）的規則不變：chain id 必須是 8017、所有帳戶餘額必須為 0。
