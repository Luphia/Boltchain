# ADR 0002：第一版不加客製交易類型或預編譯

- 狀態：已採納（2026-09-25）

## 決定

Boltchain 維持純 Osaka 的 EVM 等價性。質押、罰沒證據、共識證明、VRF 種子、CID 驗證，
都用系統合約加上既有的預編譯（EIP-2537 BLS、0x02 SHA-256、EIP-4788 環形緩衝）完成。

不做任何「在 EVM 內依 CID 讀取 IPFS 內容」的功能：執行結果會取決於節點當下抓不抓得到資料，
導致 state root 分歧。

## 後果

- 錢包、ethers/viem、Foundry 不需要任何修改。
- 風險轉移到最壞情況區塊：Osaka 的 gas 價格以 x86 校準，塞滿 pairing 預編譯的區塊
  在樹莓派上可能超過投票時間窗。M1 需做基準測試，超標時優先降低預設 gas limit。
- 類 blob 的 IPFS 資料交易等到主網上線後再依需求評估。
